## [Unreleased]

### Added

- 스프라이트 시트: **동작별 AnimationClip 자동 생성** — `Tools/MCP/Sprite Sheet` 창의 "4. 애니메이션" 섹션과 MCP 도구 `mcptools_spritesheet_build_clips`. 서브 스프라이트를 `{동작}_{번호}`로 묶어 `Assets/Generated/3_Confirmed/Animations/{시트이름}/{동작}.anim` 생성(프레임 레이트·루프 지정, idle/walk/run 기본 루프 ON). 기존 클립은 새로 만들지 않고 커브·프레임 레이트·루프만 갱신해 Animator 참조와 애니메이션 이벤트를 보존
- 스프라이트 시트: **AnimatorController 생성 옵션** — 동작별 State 배치, 기존 컨트롤러에는 없는 State만 추가(트랜지션·파라미터 보존), 대상 프리팹 지정 시 루트에 Animator 부착 + 컨트롤러 연결(Undo 지원)
- 스프라이트 시트: 임포트 **전용 행 목록**(1번 프롬프트 섹션과 분리, 행 추가/삭제/순서 변경/[1번 행 목록 가져오기])과 **검출 → 확인 → 적용 2단계 흐름** — 검출 결과 표에서 행별 동작명을 직접 입력하고 프레임별 썸네일·포함 체크로 제외할 수 있음
- `mcptools_spritesheet_import`에 `dryRun` 파라미터 — 배경 제거·격자 검출 결과(행 수, 행별 프레임 수, 셀 크기, 자동 제외된 빈 셀)만 반환하고 아무것도 기록하지 않음
- 4단계: **스프라이트 시트의 특정 프레임 적용** — 항목의 `spriteName`(예: `walk_03`)과 `spriteSheetPath`. `mcptools_apply_asset`에도 `spriteName` 파라미터 추가
- 4단계: **AnimatorController 자동 연결** — 시트를 고르면 그 시트에서 만든 컨트롤러(`Animations/{시트이름}/{시트이름}.controller`)를 찾아 [적용] 시 대상 프리팹 루트에 Animator를 붙여(있으면 재사용) 함께 연결합니다. 한 시트의 클립·컨트롤러는 한 벌뿐이므로 따로 고르지 않고, 연결될 대상만 창에 표시합니다. 스프라이트 적용과 같은 저장에서 처리되고 Undo 가능하며, 컨트롤러의 클립 커브 경로가 그 프리팹에 없으면 적용 전에 검증에서 걸러 안내합니다(씬 항목 미지원). 다른 컨트롤러를 쓰려면 항목의 `animatorControllerPath`(JSON 또는 MCP 파라미터)로 덮어쓸 수 있고, `mcptools_apply_asset`/`_apply_all`은 `linkedControllerPath`를 반환합니다
- 4단계: 스프라이트 시트를 **썸네일 그리드에서 그림을 보고 선택** — 항목 상세의 [시트 고르기 (썸네일)]에서 `Generated/3_Confirmed/SpriteSheets/`의 시트를 클릭해 고릅니다(선택 항목 강조, [해제]로 미지정)
- 설정 `spriteAnimationFrameRate`(기본 12), 출력 폴더 `Generated/3_Confirmed/Animations`
- README에 스프라이트 시트 도구 사용법 절 추가(기존 누락분)

### Changed

- 스프라이트 시트 임포트가 **자동 행 이름(`rowN`)을 붙이지 않습니다.** 이름이 빈 행이 있으면 창에서는 [슬라이스 적용]이 비활성화되고, MCP 경로는 어느 행의 이름이 비었는지 알리며 실패합니다. 시트 위/아래의 얇은 여백 줄이 행으로 검출돼 엉뚱한 동작명이 붙고 빈 스프라이트가 만들어지던 문제를 사용자가 직접 확인·수정하는 방식으로 해결
- 프레임 번호는 **포함한 프레임만** 1부터 연속으로 부여
- 격자 검출에서 **"비어 보임"으로 나온 셀을 자동 제외**합니다(전경 픽셀 비율 2% 미만). 체크를 일일이 해제하지 않아도 프레임이 없는 것처럼 처리되고, 전부 자동 제외된 행은 통째로 빠져 동작명도 필요 없습니다. 실제 콘텐츠였다면 창에서 해당 셀을 다시 체크해 되살릴 수 있으며, 자동 제외 개수는 검출 완료 메시지와 MCP 응답(`autoExcludedEmptyFrameCount`)에 표시됩니다
- 행 동작명은 **자동 제외 후 남은 행에만** 위에서부터 순서대로 배정됩니다(여백 밴드 행 때문에 이름이 밀리던 문제 해소)
- 4단계 창의 **스프라이트 시트 지정이 썸네일 선택기**로 바뀌었습니다 — 프로젝트 전체 ObjectField 대신 `Generated/3_Confirmed/SpriteSheets/`의 시트를 그림으로 보고 고릅니다(창에 포커스가 올 때마다 목록 갱신)
- 4단계 창에서 **스프라이트 이름 입력·이름 선택 드롭다운을 제거**했습니다. 시트를 고르면 **첫 프레임**이 적용됩니다(Sprite Mode=Multiple 시트는 에셋 전체 스프라이트가 없어 이전에는 null이 적용될 수 있었습니다). `spriteName` 데이터와 MCP 파라미터는 그대로라 특정 프레임 지정도 계속 가능합니다

### Fixed

- 4단계에서 RawImage 대상에 `spriteName`을 지정하면 조용히 무시된 채 시트 전체가 적용되던 문제 — 검증에서 걸러 원인·조치를 안내

> 격자 검출·배경 제거·셀 콘텐츠 판정·피벗 계산 알고리즘은 변경하지 않았습니다(분리 품질 유지). "비어 보임" 자동 제외는 검출된 셀의 기본 포함 여부만 바꾸며, 셀 후보를 만드는 판정 기준(0.5%)에는 관여하지 않습니다.

## [0.2.0] - 2026-07-25

### Added

- 1단계: 저장해 둔 `AssetList_*.json`을 불러와 이어서 편집(항목 추가/수정/삭제)하고 같은 파일에 덮어쓰는 기능
- 3단계: 항목 체크박스 + [전체]/[해제]/[미생성] 선택과 **[선택 항목 생성]** 버튼 — 체크한 항목을 현재 워크플로·변수 설정 그대로 한 번에 생성
- 3단계: 생성 창에서 항목 추가/수정/삭제 — 목록 아래 [추가]/[편집]/[삭제]/[저장] 한 줄, [추가]·[편집]은 별도 **항목 편집 창**에서 작성 후 [저장]하면 목록에 반영(레이아웃은 기존 2열 유지). [저장]은 로드한 PromptSet JSON에 덮어쓰거나 새 파일로 저장
- 3단계: 후보 개수를 생성 창에서 바로 조절하는 슬라이더(1~12, 설정 에셋 `candidateCount`와 공유)
- 3단계: 이 세션이 시작하지 않은 브리지 서버를 내리는 **[원격 종료]** 버튼, 브리지 서버 `POST /shutdown` 엔드포인트
- Unity 에디터 종료 시 이 도구로 시작한 브리지 서버를 자동 종료 (설정 `shutdownBridgeOnEditorQuit`, 기본 켬)
- 단계별 산출물 하위 폴더 — `Docs/1_AssetList`·`Docs/2_PromptSet`·`Docs/SpriteSheetPrompt`, `Generated/3_Candidates`·`Generated/3_Confirmed`(`Images`/`Audio`/`SpriteSheets`). 기존 프로젝트의 구 위치 파일도 계속 인식됩니다(읽기는 양쪽, 쓰기는 새 위치)

### Changed

- 브리지 서버 버전 0.1.0 → 0.2.0 (`/shutdown` 추가)
- 3단계 일괄 생성이 항목별 기본 워크플로 대신 **현재 선택된 워크플로와 변수 값**을 모든 대상에 적용(프롬프트만 항목별 값). 참조 이미지 업로드는 일괄 1회로 통합
- 3단계 항목 클릭 시 현재 워크플로가 이미 그 항목 종류에 해당하면 워크플로 선택을 유지 (이미지 항목을 `StyleChange`로 계속 작업 가능)
- 3단계 항목 편집 창: **대상 프리팹**을 오브젝트 필드(드래그&드롭/◎ 선택)로, **대상 오브젝트**를 프리팹 계층 드롭다운(적용 가능 컴포넌트 표시)으로 변경 — 경로 직접 입력 불필요
- 3단계 항목 편집 창: 새 항목의 positive/negative 프롬프트를 변수란 값으로 자동 채우지 않고 **빈칸으로 시작** ([생성 창의 현재 프롬프트 가져오기]로 필요할 때만 가져옴)

### Fixed

- 3단계 생성 창 오른쪽 열이 창 폭을 넘어가 잘리던 문제 — 오른쪽 열 내용을 실측한 표시 폭에 고정해 가로로 넘치지 않게 하고(세로 스크롤만 사용), 후보 격자는 그 폭으로 열 수·썸네일 크기를 계산하며, 창이 좁으면 왼쪽 열이 320→240px로 줄고 일괄 생성 버튼이 세로로 쌓입니다. 확정 에셋 경로·상태 메시지처럼 띄어쓰기 없는 긴 경로 라벨이 열을 넓혀 오른쪽을 밀어내던 것도 함께 수정
- 다른 Unity 프로젝트나 이전 에디터 세션이 띄운 브리지 서버가 포트를 쓰고 있으면 [서버 시작]·[서버 종료]가 아무 안내 없이 동시에 비활성화되던 문제 — 원인과 조치를 안내하고 [원격 종료]로 해소할 수 있게 함

## [0.1.0] - 2026-07-25

### Added

- 기획서 기반 AI 에셋 생성 4단계 파이프라인 에디터 툴 (AssetListup → PromptBuilder → ComfyUIGenerator → AssetApplier)
- ComfyUI 브리지 서버(Python): 원본 워크플로 JSON에 변수 덮어쓰기 방식으로 이미지/사운드 생성, 후보 4개 생성 및 선택 적용
- 스프라이트 시트 지원: 레퍼런스 이미지 기반 동작별 Row 통합 시트 생성·슬라이스·적용
- MCP 도구 노출: 각 파이프라인 단계를 unity-mcp(선택 의존)를 통해 MCP 도구로 호출 가능
- UPM 배포 대응: 경로 독립화, 설정 에셋 Assets 분리, preflight 검증
