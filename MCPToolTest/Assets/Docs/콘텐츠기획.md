# OUROBOROS: SWARM 콘텐츠 기획 골격 초안

- 문서 상태: 3인 4주 MVP 제작을 위한 골격 초안
- 대상 플랫폼: PC / Web, Unity 2D
- 핵심 장르: 생존 액션, 군집 전투, 몸통 자원 운용

## 1 문서 기준

| 항목      | 기준                                                                   |
| --------- | ---------------------------------------------------------------------- |
| 목표      | 4주 안에 코어 재미와 커스텀 캐릭터 가능성을 검증한다.                  |
| 핵심 질문 | 몸통을 유지할지 폭발로 소비할지 고민하는 순간이 반복해서 재미있는가?   |
| 기본 세션 | 죽을 때까지 이어지는 무한 생존, 10분 첫 보스는 종료가 아닌 마일스톤     |
| 우선순위  | 조작감 > 몸통 전투 판독성 > 성장 선택 > 콘텐츠 양                      |
| 제외 원칙 | 미로, 복잡한 서사 분기, 영구 장비 파밍, 멀티플레이는 MVP에서 제외한다. |

- 모든 수치는 첫 플레이테스트를 위한 가설값이며 데이터에 따라 조정한다.
- 넓은 필드와 드문 장애물을 유지해 이동 경로보다 군집 압박 대응에 집중한다.
- PC와 Web은 동일 규칙을 사용하고 입력 안내와 품질 옵션만 분리한다.

## 2 게임 비전/세계관

| 구분        | 내용                                                                         |
| ----------- | ---------------------------------------------------------------------------- |
| 한 줄 비전  | 늘어날수록 강해지고, 끊어낼수록 전장을 뒤집는 생존 액션                      |
| 플레이 감정 | 탐욕스러운 축적, 포위 공포, 과감한 방출, 빠른 재건                           |
| 세계관      | 붕괴한 생체 네트워크에서 자가 증식 병기 우로보로스가 군집 감염체를 정화한다. |
| 시각 방향   | 선명한 실루엣, 발광 코어, 몸통 연결선, 다수 적의 대비되는 군집색             |
| 연출 방향   | 몸통 증가 시 힘의 밀도를, 소비 시 넓은 공간이 비워지는 해방감을 강조한다.    |

- 플레이어 캐릭터는 머리 코어와 연속된 몸통 노드로 구성한다.
- 적은 개체보다 군집의 흐름이 먼저 읽히도록 형태와 색을 단순화한다.
- 장애물은 세계 잔해로 표현하되 시야를 가리거나 길찾기를 강요하지 않는다.

## 3 코어 루프

| 단계    | 행동                                              | 즉시 보상                    | 다음 선택           |
| ------- | ------------------------------------------------- | ---------------------------- | ------------------- |
| 1. 탐색 | 넓은 필드에서 적 군집과 성장 자원을 찾는다.       | 안전 공간과 교전 각도 확보   | 진입 또는 우회      |
| 2. 교전 | 이동과 자동 공격으로 적을 처치한다.               | 경험치, 몸통 조각, 회복 자원 | 수집 동선 결정      |
| 3. 축적 | 몸통을 늘려 투사체 수와 지속 화력을 높인다.       | 처치 속도 상승               | 더 유지하거나 소비  |
| 4. 위기 | 포위와 정예 패턴으로 안전 공간이 줄어든다.        | 긴장과 폭발 기회 형성        | 탈출 또는 포위 폭발 |
| 5. 방출 | 몸통을 소비해 연결 범위에 대규모 폭발을 일으킨다. | 공간 확보, 대량 처치         | 몸통 재건           |
| 6. 성장 | 레벨업 시 3개 업그레이드 중 1개를 선택한다.       | 빌드 방향 강화               | 다음 웨이브 대응    |

- 사망 시 생존 시간, 최대 몸통, 폭발 처치 수, 보스 도달/처치 기록을 요약한다.
- 20~30초 안에 축적과 방출 중 하나의 의미 있는 판단이 발생하도록 적 밀도를 설계한다.

## 4 조작·전투·몸통

| 기능      | 기본안                                   | 설계 의도                                                                   |
| --------- | ---------------------------------------- | --------------------------------------------------------------------------- |
| 이동      | WASD / 방향키, 8방향 자유 이동           | Web에서도 즉시 이해 가능한 조작                                             |
| 기본 공격 | 가장 가까운 적을 향해 자동 발사          | 이동과 몸통 판단에 집중                                                     |
| 포위 폭발 | 몸통 루프 안에 적을 감싸면 자동 발동, 보유 몸통의 30% 소비 | 위기 탈출과 고효율 공격의 공용 수단                                         |
| 조준 보정 | 사거리 내 가장 가까운 적, 정예 우선 옵션 | 군집 속 핵심 표적 대응                                                      |
| 피격      | 머리 코어만 충돌 판정, 짧은 무적 0.6초   | 긴 몸통으로 인한 불합리한 피격 존재 머리 외의 부분은 피격시 피격부분이 끊킴 |

- 몸통은 최대 제한이 없고 자신의 몸통과는 충돌 판정이 발생하지 않는다.
- 5칸마다 보조 투사체 1개를 추가해 성장 체감을 시각적으로 전달한다.
- 몸통 조각 획득 게이지가 가득 차면 꼬리에 1칸을 즉시 추가한다.
- 포위 폭발은 머리와 몸통이 닫힌 루프를 만들고 그 안에 생존 적이 있을 때 자동으로 예고 후 발동하며, 소비된 꼬리 구간을 따라 한번에 폭발한다.
- 폭발 피해와 범위는 소비 칸 수에 비례하며 최소 발동 조건은 몸통 4칸이다.
- 발동 전 0.25초 예고선, 발동 후 0.4초 무적을 제공해 플레이어가 포위 성공과 위험 해소를 읽을 수 있게 한다.
- 몸통이 1개씩 생성될때 4가지 역할의 종류의 몸통을 선택해서 생겨나도록 한다.
  - 실드 생성 몸통 : 실드 몸통 인근에 적을 1번 막을 수 있는 일정범위 보호막을 생성한다.
  - 공격 몸통 : 총을 발사하는 몸통을 생성한다.
  - 레이저 몸통 : 적을 관통하는 레이저를 발생한다.
  - 제어 몸통 : 적을 일정시간 움직이지 못하게 하는 총을 발생한다.(데미지는 없음)

## 5 성장·업그레이드

| 계열      | 업그레이드 예시                                 | 최대 단계 |
| --------- | ----------------------------------------------- | --------- | --------------------------------- |
| 지속 화력 | 기본 피해 +15%, 발사 속도 +12%, 관통 +1         | 각 3      |
| 몸통      | 최대 몸통 +3, 조각 요구량 -10%, 칸당 피해 +1%p  | 각 2      | (4가지 몸통 종류중 선택해서 등장) |
| 폭발      | 폭발 범위 +15%, 피해 +20%, 소비율 -10%p         | 각 3      |
| 생존      | 최대 체력 +20%, 이동 속도 +8%, 회복 획득량 +25% | 각 2      |
| 유틸      | 자석 범위 +30%, 경험치 +10%, 정예 탐지 우선     | 각 2      |

- 레벨업 시 중복 없는 3개 선택지를 제시하고 선택 중 게임을 일시 정지한다.
- 초반 3레벨에는 공격, 몸통, 생존 계열이 최소 1개씩 등장하도록 보정한다.
- 동일 계열 누적 시 강해지되 폭발과 지속 화력의 혼합 빌드도 유효하게 유지한다.
- MVP에는 희귀도와 합성 없이 총 15종 내외 업그레이드만 제공한다.

## 6 적·웨이브·보스

| 유형         | 역할      | 핵심 행동                     | 대응                      |
| ------------ | --------- | ----------------------------- | ------------------------- |
| 추적체       | 기본 압박 | 플레이어를 직선 추적          | 이동하며 지속 사격        |
| 돌진체       | 진형 붕괴 | 예고 후 빠르게 돌진           | 측면 회피                 |
| 사격체       | 공간 제한 | 멈춰서 느린 탄 발사           | 우선 처치                 |
| 분열체       | 밀도 증가 | 사망 시 소형 적 2개 생성      | 폭발 연쇄 활용            |
| 정예체       | 중간 목표 | 강화 체력과 주변 적 가속 오라 | 몸통 축적 후 집중 공격    |
| 보스: 군집핵 | 최종 검증 | 흡인, 부채꼴 탄, 소환, 보호막 | 축적과 폭발을 교대로 사용 |

- 웨이브는 시간 기반으로 진행하며 초반에는 60초마다 적 조합을 한 단계 확장한다.
- 3분과 6분에 정예체, 9분에 보스 예고, 10분에 첫 군집핵을 등장시킨다. 첫 보스 이후에는 죽을 때까지 20초 단위 무한 압박과 반복 정예/보스 마일스톤을 이어간다.
- 장애물은 세션당 6~10개 배치하고 적과 플레이어 모두 충돌하되 투사체는 통과시킨다.

## 7 세션·난이도

| 구간 |       시간 | 목표 상태                     | 압박 요소               |
| ---- | ---------: | ----------------------------- | ----------------------- |
| 도입 |  0:00~1:30 | 이동·공격·첫 몸통 습득        | 느린 추적체 중심        |
| 성장 |  1:30~4:00 | 몸통 6~10칸, 첫 폭발 학습     | 돌진체와 첫 정예        |
| 분기 |  4:00~7:00 | 지속 화력 또는 폭발 빌드 형성 | 사격체·분열체 혼합      |
| 한계 |  7:00~9:00 | 몸통 소비 타이밍 숙련         | 고밀도 군집과 정예 중첩 |
| 결전 | 9:00~11:00 | 보스 처치                     | 소환 군집과 보스 패턴   |

- 기본 난이도 목표는 첫 판 4~6분 생존, 세 번째 판 보스 도달이다.
- 적 생성량은 시간, 현재 적 수, 플레이어 레벨을 함께 참조해 상한을 둔다.
- Web 저사양 대응을 위해 활성 적 180마리, 투사체 120개를 1차 상한으로 둔다.
- 세션은 보스 처치로 종료하지 않고 사망할 때만 종료한다. 사망 원인은 마지막 피해원과 위험 신호를 결과 화면에 표시한다.

## 8 UI/튜토리얼

| 화면 요소  | 위치/방식               | 표시 정보                      |
| ---------- | ----------------------- | ------------------------------ |
| 체력       | 좌상단 고정 바          | 현재/최대 체력, 피격 점멸      |
| 몸통       | 체력 아래 분절 게이지   | 현재/최대 칸, 폭발 소비 예상량 |
| 경험치     | 화면 상단 얇은 바       | 레벨과 다음 선택까지 진행도    |
| 타이머     | 상단 중앙               | 생존 시간, 정예·보스 예고      |
| 폭발 안내  | 캐릭터 주변 반투명 범위 | 예상 연쇄 범위, 소비 칸 수     |
| 업그레이드 | 중앙 3열 선택 패널      | 아이콘, 이름, 효과, 현재 단계  |

- 첫 세션은 이동, 자동 공격, 몸통 획득, 적 포위로 자동 폭발시키는 흐름을 순서대로 상황 안내한다.
- 안내는 조건 달성 즉시 닫히며 각 단계는 최대 한 문장과 키 아이콘으로 제한한다.
- 체력 위험, 폭발 가능, 보스 패턴은 색뿐 아니라 형태와 음향으로 중복 전달한다.
- 결과 화면은 사망 후 생존 기록, 도달한 보스/마일스톤, 재시작, 캐릭터 변경, 메인 메뉴를 한 번의 입력으로 제공한다.

## 9 커스텀 캐릭터 ComfyUI UX

| 단계           | 사용자 경험                               | 시스템 처리                      |
| -------------- | ----------------------------------------- | -------------------------------- |
| 1. 업로드      | JPG/PNG 1장을 선택하고 이용 동의 확인     | 형식·용량·해상도 검증            |
| 2. 미리보기    | 얼굴/전신 크롭 영역과 배경 제거 결과 확인 | 안전성 검사와 전처리             |
| 3. 스타일 선택 | 기본 제공 2D 스타일 프리셋 3종 중 선택    | 고정 워크플로와 프롬프트 적용    |
| 4. 생성 대기   | 진행 단계, 예상 대기, 취소 버튼 표시      | ComfyUI API 비동기 작업 조회     |
| 5. 검수        | 생성된 머리 스프라이트 3안 중 1개 선택    | 크기·투명도·팔레트 후처리        |
| 6. 적용        | 연습 화면에서 확인 후 캐릭터 슬롯 저장    | 로컬 캐시와 게임용 아틀라스 등록 |

- MVP 적용 범위는 머리 코어 스프라이트 1종이며 몸통은 공용 디자인을 사용한다.
- 원본 이미지는 생성 완료 또는 취소 후 즉시 삭제하고 보관 정책을 명시한다.
- 실패 시 원인별 재시도, 기본 캐릭터로 계속하기, 작업 취소를 제공한다.
- API 미연결 환경에서는 사전 생성 샘플로 전체 UX를 검증할 수 있게 한다.
- 금지 이미지, 타인 권리 침해, 미성년자 관련 안내와 동의 체크를 업로드 전에 배치한다.

## 10 3인 4주 MVP

| 주차 | 클라이언트/테크                                     | 콘텐츠/기획           | 아트/UI                      | 완료 조건                      |
| ---- | --------------------------------------------------- | --------------------- | ---------------------------- | ------------------------------ |
| 1주  | ComfyUI 연동 또는 이동, 자동 공격, 몸통 데이터 구조 | 코어 규칙·수치표      | 플레이어·기본 적 임시 리소스 | 축적/폭발 루프 플레이 가능     |
| 2주  | 적 4종, 웨이브, 업그레이드                          | 웨이브 초안·15종 성장 | HUD·이펙트 1차               | 7분 생존 빌드 가능             |
| 3주  | 보스, 사망 결과, Web 최적화, QA 테스트              | 무한 난이도 1차 조정  | 보스·UI·사운드 적용          | 10분 첫 보스 이후 무한 진행 가능 |
| 4주  | 빌드 및 목업, 버그 수정                             | 플레이테스트·밸런스   | 가독성·연출 마감             | 배포 빌드와 시연 시나리오 확보 |

- 역할 기준은 프로그래머 1명, 기획 겸 콘텐츠 1명, 아트 겸 UI 1명이다.
- 매일 실행 가능한 빌드를 유지하고 주 2회 30분 내부 플레이테스트를 진행한다.
- 필수 범위는 캐릭터 1종, 적 4종, 정예 1종, 보스 1종, 맵 1종이다.
- ComfyUI 실연동이 3주차 종료까지 불안정하면 목업 UX와 사전 생성 샘플로 전환한다.

| 플레이어 체력 / 이동 속도 |                     100 / 초당 5.5 | 평균 생존 시간, 회피 성공률 |
| 기본 공격                 |        피해 10, 초당 2발, 사거리 6 | 분당 처치 수                |
| 몸통                      | 시작 2칸, 최대 20칸, 칸당 피해 +4% | 평균·최대 보유 칸           |
| 몸통 획득                 |       일반 적 조각 1, 필요 조각 12 | 몸통 1칸 획득 시간          |
| 포위 폭발                 |   30% 소비, 칸당 피해 35, 반경 1.8, 자동 포위 발동 | 발동 간격, 1회 처치 수      |

- 목표 포위 폭발 간격은 35~50초, 평균 처치 수는 15~30마리다.
- 몸통 최대 유지 빌드와 반복 소비 빌드의 보스 처치 시간을 20% 이내로 맞춘다.
- 프레임 저하가 전투 난이도로 변하지 않도록 생성 상한과 이펙트 풀링을 함께 검증한다.

## 12 수용 기준·백로그

| 구분      | 수용 기준                                                           |
| --------- | ------------------------------------------------------------------- |
| 코어 재미 | 테스터 70% 이상이 몸통 유지와 소비 사이에서 고민했다고 응답한다.    |
| 조작      | 첫 플레이 60초 안에 별도 설명 없이 이동과 자동 공격을 이해한다.     |
| 폭발      | 포위 성공 전 소비량과 범위를 예측할 수 있고 자동 발동 후 0.5초 안에 반응한다. |
| 가독성    | 적 150마리 상황에서 플레이어 머리, 위험 공격, 경험치가 구분된다.    |
| 세션      | 치명적 진행 막힘 없이 시작부터 10분 첫 보스, 10분 이후 무한 스폰, 사망 결과 화면까지 10회 연속 완료한다. |
| 성능      | 목표 기기에서 PC 60fps, Web 30fps 이상을 전투 피크에도 유지한다.    |
| 커스텀    | 성공·실패·취소·기본 캐릭터 대체 경로가 모두 끊김 없이 동작한다.     |

- P0 백로그: 저장 없는 즉시 재시작, 입력 리바인딩 최소안, Web 메모리 점검.
- P1 백로그: 캐릭터 슬롯 3개, 업그레이드 도감, 난이도 선택, 게임패드 지원.
- P2 백로그: 추가 맵, 보스 변형, 영구 해금, 일일 도전, 생성 스타일 확장.
- MVP 출시 판단은 P0 수용 기준 통과와 3회 외부 플레이테스트 결과로 결정한다.
- 보류 항목은 미로형 맵, 온라인 협동, 사용자 생성 몸통, 계정 기반 이미지 보관이다.
