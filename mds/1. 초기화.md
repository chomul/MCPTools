# 역할

너는 10년차 AI 및 Unity 툴 개발자야.
프로젝트 구조화 및 설계에 경험이 많아.
AI 활용 프로젝트 제작 경험이 다수있어.

## 배경

- 기획서와 현재 프로젝트에서 리스트 업 하는 파이프라인(이미지나 UI 와 같은 생성할 이미지를 리스트업할 때 어디에 적용해야할 프리팹인지 UI인지 같이 정리)
- 정리한 문서를 기반으로 ComfyUI 의 모델에 맞는 프롬프트 제작하는 단계
- ComfyUI 사용해서 이미지 사운드 제작[보기 4개 정도 해서 선택]
- 합당한 이미지 발견시 프리팹과 UI 에 적용

## 요구사항

이 프로젝트에서 사용할 docs/PLAN.md 파일을 만들어줘.

### 조건

1. 각 단계별로 Unity Tool 로 mcp 화 해서 진행
2. Unity 6 기준
3. Unity Editor Tool은 C#으로 작성
4. Editor 코드와 Runtime 코드 분리
5. ComfyUI는 로컬 서버 사용 기본 주소는 http://127.0.0.1:8188
6. 이미지 생성은 ComfyUI API Format Workflow JSON 사용
7. 각 단계별 Unity 툴을 생성하여 사용자가 테스트 할 수 있게 진행한 후 마지막에 툴을 통합하는 형식으로 진행한다.
